# Peruvian Gold Harvest

Quiero crear un sitio web corporativo, moderno, elegante y profesional para una empresa peruana dedicada a la producción, comercialización y venta de aguaymanto.

El sitio debe proyectar una imagen de empresa seria, confiable, natural, moderna y orientada tanto a clientes particulares como a empresas, restaurantes, tiendas, distribuidores y compradores mayoristas.

El diseño debe tener una identidad visual relacionada con el aguaymanto, la agricultura peruana, la naturaleza y la calidad del producto.

No quiero una página que parezca una plantilla genérica. Debe parecer el sitio web de una empresa agrícola/alimentaria profesional y consolidada.

1. OBJETIVO DEL SITIO

Los objetivos principales son:

Presentar profesionalmente la empresa.

Explicar quiénes somos y qué hacemos.

Mostrar nuestros productos.

Presentar nuestros servicios.

Mostrar la calidad y origen del aguaymanto.

Publicar noticias y novedades de la empresa.

Generar confianza en potenciales clientes.

Conseguir consultas y pedidos.

Facilitar el contacto por WhatsApp, teléfono y formulario.

Captar clientes mayoristas y empresariales.

El sitio debe estar diseñado pensando en conversión, pero manteniendo una imagen corporativa elegante.

Crear una página web que parezca una empresa agrícola peruana profesional y moderna.

CALIDAD + NATURALEZA + ORIGEN PERUANO + CONFIANZA + PROFESIONALISMO
